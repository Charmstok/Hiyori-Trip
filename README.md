# 日和旅 · Hiyori Trip

把旅程排成喜欢的样子。

在自己电脑上运行的日本旅行规划网页：地图选城市，按日期整理行程，导出图片与 PDF。行程自动保存到项目内的 SQLite 数据库，无需账号、API Key 或外部服务。

## 本地运行

需要 **Node.js 24+** 与 npm。首次安装依赖需要网络，安装完成后可以断网使用。

```sh
npm install
npm start
```

在浏览器打开 **http://127.0.0.1:4317/**，保持终端运行，按 `Ctrl+C` 停止。程序只监听本机回环地址，固定使用 4317 端口；端口被占用时会直接报错。

`npm start` 会先构建网页，再启动本机程序。开发时使用 `npm run dev` 可自动更新页面。如需单独构建并启动：

```sh
npm run build
# 先停止 start/dev，再运行：
npm run preview
```

本项目只供本地使用，没有登录、云同步或线上部署配置。Node.js 本地进程负责读写 SQLite 和保存导出文件，网页与该进程通过同一个本机地址通信。请通过本地服务打开，不要直接双击 `index.html`。

## 能做什么

- 简约日本地图，点击地区聚焦放大，用引线相连的城市卡片选择目的地；可随时返回全日本。
- 22 个离线城市目的地，中日文城市名称对照。城市选择按日本国家旅游局的地区顺序分组，也可手动填写其他城市。
- 选择出发与返回日期，自动生成每日行程，日期包含出发与返回当日。
- 旅程名称可留空，默认使用第一站城市名；未选择城市时使用“我的日本之旅”。
- 创建、搜索、复制和删除旅程，添加可修改的关西示例。
- 整段旅程删除后移入“最近删除”，可恢复全部内容；在其中确认永久删除，才会清除旅程、日期和安排。不会自动清空最近删除。
- 按天添加安排，填写时间、时长、类型、城市、地址、备注和日元花费。
- 预计花费的加减按钮和键盘上下键每次增减 100 日元，也可直接输入金额。
- 拖动手柄或使用上移、下移按钮排序；把安排拖到左侧任意日期，可直接跨天移动，也可在表单中选择日期。
- 旅行日历提供“待规划”区，先收藏地点，再拖到具体日期；已安排的地点也能拖回待规划。
- 日期可增删和调换顺序；缩短旅程时会阻止直接移除包含内容的日期。
- 每日主题、每日随手记和整段旅程备注在输入时自动保存，其他表单在确认后自动写入数据库。
- 最近 20 次行程编辑可撤销，预计花费自动合计。
- 导出单张 PNG、全部日期 PNG 的 ZIP，以及含封面、行程一览、待规划和备注的 A4 PDF。待规划也能单独导出为图片。
- 长行程图片自动分图，PDF 文字可选择，字体随项目附带。
- 可额外保存 SQLite 数据库副本。

地图的轮廓、城市位置与连线用于规划示意，冲绳为单独插图；连线不代表真实交通路线。地点建议没有实时营业、票价、交通或预约数据。

## 数据与导出文件

数据与文件均位于项目目录内：

```text
.local-data/
  hiyori.sqlite        行程数据库
  hiyori.sqlite-wal    运行时可能出现的 SQLite 日志
  hiyori.sqlite-shm    运行时可能出现的 SQLite 辅助文件
exports/               PNG、PDF、ZIP 与 SQLite 备份
```

- 行程、日期和安排分别存入 SQLite 数据表，写入采用事务；不以 JSON 文件保存行程。
- 最近删除同样保存在 SQLite，重启后仍可恢复；单个安排和日期的删除维持原有操作。
- 修改自动写入磁盘，页面右上角显示保存状态。保存异常时会提示重试，并在离开页面前提醒。
- 数据不依赖浏览器缓存。更换浏览器、清除站点数据后，仍能读取这份 SQLite 数据库。
- 升级后，使用原来的浏览器和地址打开一次，即可自动迁移旧版 IndexedDB 中的行程。迁移保留原数据，同一份旧行程不会重复导入。
- 每段旅程支持 1–60 天，每天及待规划区分别最多 200 段安排。待规划不计入旅行天数，花费合计包含已收藏的安排。
- 旧 SQLite 数据库通过事务原地升级，失败时回滚，不自动生成升级副本。
- 导出成功后弹窗显示文件的完整绝对路径；同名文件自动编号，避免覆盖。
- `.local-data/`、`exports/`、`backups/` 和本地开发工作目录均已加入 `.gitignore`，不会提交个人行程或导出文件。

备份整个项目的数据可以使用“备份数据库”，会在 `exports/` 生成一致的 `.sqlite` 副本。恢复时，先停止日和旅，将现有 `.local-data/` 移到别处保留，再新建该目录，将备份复制为 `.local-data/hiyori.sqlite`，然后启动程序。不要在程序运行时替换数据库。

地图、字体与图标都随项目附带；运行时不加载远程字体、地图、统计脚本或广告。导出在本地生成，再写入项目目录。

## 技术结构

React、TypeScript、Vite、Zustand、Node.js 内置 SQLite、dnd-kit、SVG/d3-geo、html-to-image、@react-pdf/renderer、fflate、Lucide。

```text
server/            本机 HTTP 进程、SQLite 表与文件保存
src/
  components/      地图、主页、编辑器、表单与导出视图
  data/            日本地图、地区轮廓与离线城市内容
  lib/             行程操作、本地存储、数据校验、图片分页与 PDF
  styles/          响应式样式
public/fonts/      本地字体与许可
```

开发记录与工作文件位于 `.local-dev/`，整个目录已加入 `.gitignore`。
