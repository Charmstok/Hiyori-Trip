# 日和旅 · Hiyori Trip

把旅程排成喜欢的样子。

在自己电脑上运行的日本旅行规划网页：地图选城市，搜索具体地点，按日期整理行程，导出图片与 PDF。行程自动保存到项目内的 SQLite 数据库，无需账号或 API Key。详细底图与地点搜索需要联网。

## 本地运行

需要 **Node.js 24+** 与 npm。首次安装依赖需要网络；安装完成后，行程编辑和导出可以离线使用，详细地图与地点搜索需要网络。

```sh
npm install
npm start
```

在浏览器打开 **http://127.0.0.1:4317/**，保持终端运行，按 `Ctrl+C` 停止。程序只监听本机回环地址，固定使用 4317 端口；端口被占用时会直接报错。

`npm start` 会先构建网页，再启动本机程序。开发时使用 `npm run dev` 可自动更新页面。如需单独构建并启动：

```sh
npm run build
# 先停止 start/dev，再运行：
npm run preview
```

本项目只供本地使用，没有登录、云同步或线上部署配置。Node.js 本地进程负责读写 SQLite 和保存导出文件，网页与该进程通过同一个本机地址通信。请通过本地服务打开，不要直接双击 `index.html`。

## 能做什么

- 简约日本地图，点击地区聚焦放大，用引线相连的城市卡片选择目的地；可随时返回全日本。
- 主页提供 22 个常用目的地。创建旅程、添加安排和地图探索采用“地区 → 都道府县 → 城市”的中文级联选择，覆盖 47 个都道府县、1,916 个城市/市区町村及整市入口，也可手动填写地名。
- 选择出发与返回日期，自动生成每日行程，日期包含出发与返回当日。
- 旅程名称可留空，默认使用第一站城市名；未选择城市时使用“我的日本之旅”。
- 创建、搜索、复制和删除旅程，添加可修改的关西示例。
- 关西参考行程中的 10 个真实地标附带参考坐标和地址；“当地午餐”保留待选。已有内置参考行程会补全尚未定位的地点，用户确认过的位置与自行填写的地址不被覆盖。
- 整段旅程删除后移入“最近删除”，可恢复全部内容；在其中确认永久删除，才会清除旅程、日期和安排。不会自动清空最近删除。
- 按天添加安排，填写时间、时长、类型、城市、地址、备注和日元花费。
- 行程编辑器以可拖动、缩放的详细地图为主体，较窄的玻璃质感行程面板浮在地图上，可随时收起为地图左侧的长条日历，收起时仍能切换日期；缩小窗口时地图仍保留。搜索具体景点、车站、餐厅或地址，选中后加入当天或待规划；也可在地图上手动选点。
- 安排保存准确地址、经纬度和定位来源，点击已定位的安排名称会自动聚焦并高亮对应地点，再次点击可重新定位；地图会避开浮动面板。地图直接显示安排名称；未定位安排的名称仅展示，使用“编辑 / 移动”修改内容。旧版城市中心坐标显示为待定位，避免误当作景点位置。
- 当天已定位地点按安排顺序连线，并显示相邻地点的直线距离。交通路线通过按钮打开 Google 地图查看公共交通方案。
- 地图区域支持鼠标滚轮、触控板双指开合和触屏双指缩放；手势以地图中的位置为中心，页面其他区域仍可正常缩放。
- 预计花费的加减按钮和键盘上下键每次增减 100 日元，也可直接输入金额。
- 拖动手柄或使用上移、下移按钮排序；把安排拖到面板上方的日期，可直接跨天移动，也可在表单中选择日期。
- 旅行日历使用可滚动的日期网格，并提供完整日期下拉框，方便查看 Day 4 及之后的日期，最长 60 天；提供“待规划”区，先收藏地点，再拖到具体日期；已安排的地点也能拖回待规划。
- 日期可增删和调换顺序；缩短旅程时会阻止直接移除包含内容的日期。
- 每日主题、每日随手记和整段旅程备注在输入时自动保存，其他表单在确认后自动写入数据库。
- 最近 20 次行程编辑可撤销，预计花费自动合计。
- 导出单张 PNG、全部日期 PNG 的 ZIP，以及含封面、行程一览、待规划和备注的 A4 PDF。待规划也能单独导出为图片。
- 长行程图片自动分图，PDF 文字可选择，字体随项目附带。
- 可额外保存 SQLite 数据库副本。

主页日本地图的轮廓和城市位置用于规划示意，冲绳为单独插图。编辑器详细地图中的虚线同样只是行程顺序示意，不代表实际步行、驾车或铁路路线。地点建议没有实时营业、票价、交通或预约数据。

## 数据与导出文件

行程数据库与手动数据库备份位于项目内；旅行图片、PDF 和 ZIP 保存到当前用户的下载目录：

```text
.local-data/
  hiyori.sqlite        行程数据库
  hiyori.sqlite-wal    运行时可能出现的 SQLite 日志
  hiyori.sqlite-shm    运行时可能出现的 SQLite 辅助文件
exports/               手动 SQLite 备份
~/Downloads/           PNG、PDF 与行程图片 ZIP（Linux 优先采用 XDG 下载目录）
```

- 行程、日期和安排分别存入 SQLite 数据表，写入采用事务；不以 JSON 文件保存行程。
- 最近删除同样保存在 SQLite，重启后仍可恢复；单个安排和日期的删除维持原有操作。
- 修改自动写入磁盘，页面右上角显示保存状态。保存异常时会提示重试，并在离开页面前提醒。
- 数据不依赖浏览器缓存。更换浏览器、清除站点数据后，仍能读取这份 SQLite 数据库。
- 升级后，使用原来的浏览器和地址打开一次，即可自动迁移旧版 IndexedDB 中的行程。迁移保留原数据，同一份旧行程不会重复导入。
- 每段旅程支持 1–60 天，每天及待规划区分别最多 200 段安排。待规划不计入旅行天数，花费合计包含已收藏的安排。
- 旧 SQLite 数据库通过事务原地升级，失败时回滚，不自动生成升级副本。
- PNG、PDF、ZIP 直接写入当前用户的下载目录，macOS 为 `/Users/用户名/Downloads`；Linux 读取 `XDG_DOWNLOAD_DIR` 或 `~/.config/user-dirs.dirs`，未设置时使用 `~/Downloads`。不会把 macOS 路径硬编码到 Linux。
- 导出成功后弹窗显示文件的完整绝对路径；同名文件自动编号，避免覆盖。已有项目 `exports/` 中的导出文件仍保留，新文件按下载目录规则保存。
- `.local-data/`、`exports/`、`backups/` 和本地开发工作目录均已加入 `.gitignore`，不会提交个人行程或导出文件。

备份整个项目的数据可以使用“备份数据库”，会在 `exports/` 生成一致的 `.sqlite` 副本。恢复时，先停止日和旅，将现有 `.local-data/` 移到别处保留，再新建该目录，将备份复制为 `.local-data/hiyori.sqlite`，然后启动程序。不要在程序运行时替换数据库。

主页示意地图、城市名单、字体与图标随项目附带，不加载远程字体、统计脚本或广告。导出在本地生成，再写入下载目录。

## 详细地图与地点搜索

- 使用 Leaflet 和 [OpenStreetMap 标准底图](https://operations.osmfoundation.org/policies/tiles/)，保留署名，使用浏览器正常缓存；只加载当前查看区域，不批量下载离线地图。
- [Photon](https://github.com/komoot/photon) 提供日本境内地点搜索。按下搜索或回车才发起查询，不在输入时请求，也不自动查询旧行程。使用日文或英文名称通常更准确；结果需按名称、地址和地图位置确认。
- 查询通过本机进程发送地点关键词和当前城市附近的坐标，结果在内存中缓存一小时（最多 100 份）；串行请求至少间隔 1.1 秒。整段旅程、日期、备注和费用不会发送给搜索服务。选中的地址和位置写入 SQLite。
- 免费公共服务可能限流或暂时不可用；页面会提示错误，允许重试或手动选点。底图不可用时，已有安排和坐标仍可编辑；未定位的安排也可正常保存。
- 交通路线按钮通过 Google Maps URL 打开外部地图，发送目的地以及已定位的上一站坐标；不需要 Google Maps API Key。网页不会读取设备当前位置。
- 如 Photon 公共端点发生调整，可在启动时设置 `HIYORI_PHOTON_URL` 为兼容 Photon API 的搜索地址，无需改动代码。

## 技术结构

React、TypeScript、Vite、Zustand、Node.js 内置 SQLite、dnd-kit、Leaflet、SVG/d3-geo、html-to-image、@react-pdf/renderer、fflate、Lucide。

```text
server/            本机 HTTP 进程、SQLite 表与文件保存
src/
  components/      地图、主页、编辑器、表单与导出视图
  data/            日本地图、地区轮廓与离线城市内容
  lib/             行程操作、本地存储、数据校验、图片分页与 PDF
  styles/          响应式样式
public/fonts/      本地字体与许可
```

开发记录与工作文件位于 `.local-dev/`，整个目录已加入 `.gitignore`。
