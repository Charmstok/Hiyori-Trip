# 旅行 Agent

## 开始使用

1. 更新依赖后运行 `npm start`。若已有旧进程，请先用 `Ctrl+C` 停止，再重新启动。
2. 点击「旅行 Agent」，填写 API Key、Base URL 和服务商提供的模型名称。使用官方 OpenAI SDK 的 Chat Completions 接口；Base URL 应类似 `https://api.openai.com/v1`，无需附加 `/chat/completions`。
3. 点击「加密保存配置」即可使用，重启后会自动读取，无需解锁密码。可先「测试连接」，此操作会向配置的服务发送一次简短请求，可能计费。
4. 输入旅行要求、出发与返回日期，添加参考材料，生成草案。支持继续补充要求调整；预览后点击「保存为旅程」，进入现有行程编辑器继续编辑或导出。

工具调用模式允许 Agent 查找少量关键地点并提交结构化草案。服务商不支持工具时可切换为 JSON 兼容模式；也可调整输出参数 `max_completion_tokens` / `max_tokens`、输出上限及可选 Organization / Project。不支持的接口参数会显示配置提示，不会自动重复计费重试。

输出上限默认 **32,768 tokens**，可设置 **1,024–262,144**。原来保存的默认值 8,192 会自动升级一次，其他自定义值保持；升级后仍可自行调低。项目允许的范围不代表模型实际支持的最大输出，超过模型上限时需按服务商要求降低。`max_completion_tokens` 会计入推理与其他不可见输出，因此 token 数不等于可见文字字数。

长行程采用流式接收，界面会提示正在推理或输出安排。单次模型请求最长等待 10 分钟，整次 Agent 规划最长 15 分钟，可随时取消；「测试连接」等待最多 20 秒。网络中断、请求超时和服务商 HTTP 错误会分别提示，失败不会自动重试或覆盖之前的草案。兼容服务即使返回普通 JSON，也会读取同一次响应，不额外发起付费请求。

## 参考材料

- **链接**：读取公开网页的正文、文章元数据及可访问的小红书笔记数据，不使用浏览器登录信息、不执行网页脚本。短链最多跟随 5 次跳转；需要登录、验证码或禁止读取时，请粘贴正文或上传截图。
- **文字**：直接粘贴攻略、偏好和大致计划；可添加 UTF-8 的 TXT、Markdown、CSV、TSV。
- **表格**：支持 XLSX，多工作表转为文本，仅读取单元格值，不执行公式或宏。旧 XLS 请另存为 XLSX / CSV。文件解压大小、工作表数与单元格范围有上限，超大表格请先只保留旅行相关部分。
- **图片**：支持 PNG、JPEG、WebP；由用户选择的视觉模型理解内容，不使用其他 OCR 服务。

最多 5 份附件或链接，其中最多 4 张图片；单份附件最多 8 MB，文字文件最多 1 MB。每份材料最多保留 40,000 字符，截取时界面会标记并可预览。一次可生成 1–30 天，过长输出需提高上限或缩小范围。未核实的地点保留待定位；交通耗时、费用和营业信息需在出行前确认。

## 本地保存与加密

- 模型配置的所有字段以及最近一份草案都以 **AES-256-GCM** 加密存入独立的 `.local-data/agent.sqlite`。程序自动生成随机的 256 位本地密钥，每次写入使用随机 nonce；配置与草案使用不同的认证上下文。
- 本地密钥单独保存在 `.local-data/agent.key`，由程序自动管理，文件权限为 `0600`。无需设置密码或手动解锁；API Key 不以明文写入数据库、日志、localStorage 或 IndexedDB。
- API Key 只在首次填写或更换时发送到本机服务；读取配置的接口不会回显 Key，模型请求在 Node.js 服务端执行，浏览器不直接连接模型服务。修改配置时 Key 留空即可保留原值。
- 数据目录权限为 `0700`，凭据数据库为 `0600`；模型 API 使用 HTTPS，本机模型允许 `http://localhost` / `http://127.0.0.1`。模型请求禁止跟随跳转，SDK 关闭请求日志与自动重试，错误提示不回传服务商原始响应。
- 网页读取拒绝本机、局域网和保留地址，逐次检查跳转并在连接时固定已验证的 DNS 地址；附件和模型输出有大小与结构限制。Agent 仅能查找地点和提交草案，不能读取密钥、执行代码或自动预订。
- 原始文字、网页正文、表格和图片仅在本次处理的内存中使用；最近草案自动加密保存，明确采用后作为普通旅程写入 `hiyori.sqlite`。现有旅程数据库本身不做整库加密。
- `.local-data/` 已被 Git 忽略；现有「备份数据库」只备份旅程数据库，不包含独立的模型配置库。复制凭据库到其他位置时需同时保管 `agent.key`；缺少本地密钥将无法解密。此前保存过旧版密码配置时，需重新填写一次模型信息，之后即可自动使用，已保存的旅程不受影响。

调用模型时，本次材料和选择继续调整的草案会发送到用户配置的服务商，其存储与使用政策由该服务商决定。可选地点检索仅向 Photon 发送地点关键词。这种方式用于避免 API Key 明文落盘；能够同时读取数据库和本地密钥的程序仍可解密，请保护好本机账户与数据目录。

接口实现参考 [OpenAI SDK](https://developers.openai.com/api/docs/libraries)、[Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create) 和 [图片输入](https://developers.openai.com/api/docs/guides/images-vision)。
